# Embedded C++ companion
The Python graph toolkit remains the full reference. `cpp/core.hpp` provides a C++11 fixed-size (16 vertices) adjacency-matrix Dijkstra engine for offline robotics route decisions. Nodes are integer IDs (unlike Python's hashable IDs); no JSON, dynamic allocation, geospatial information, or device control is included. Invalid edges latch a fault; call reset() to clear. A missing path returns false. Positive finite edge weights are required; zero is permitted. On Uno the 16x16 double matrix may exceed practical SRAM after stack and other allocations: reduce N for AVR or use ESP32. No physical motion should be controlled without independent collision avoidance and emergency stop.
Run: `cmake -S . -B build && cmake --build build && ctest --test-dir build --output-on-failure`.
Python regression: `python -m unittest discover -s tests -v`. GCC/Clang and Python are configured in GitHub Actions. Board builds and physical testing have NOT been performed.
